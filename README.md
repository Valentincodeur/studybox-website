# StudyBox Website

A clean, modern homepage for StudyBox with Apple-inspired design aesthetic.

## 🎨 Design Features

- **Color Palette:**
  - Primary Blue: `#0e0c82`
  - Modern Gray: `#cfcede`
  - Black & White accents

- **Typography:** Inter font family
- **Style:** Minimal, spacious, high-end aesthetic inspired by Apple.com

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```

## 📁 Project Structure

```
/app
  ├── layout.js          # Root layout with Navbar & Footer
  ├── page.js            # Homepage with Hero & Product sections
  └── globals.css        # Global styles with Tailwind

/components
  ├── Navbar.jsx         # Sticky navigation bar
  └── Footer.jsx         # Footer with links

/styles                  # (Using Tailwind via globals.css)
```
